// The original assertion fails because cycles_counter is a register updated on the clock edge, so its updated value is visible only in the next cycle after valid_i is asserted. The assertion incorrectly checks cycles_counter in the same cycle as valid_i, which is before the register update. The fix is to check cycles_counter in the next cycle and use $past() to refer to valid_i and op_32bits_i in the precondition cycle.

as__CyclesCounterLoadCorrect: assert property (@(posedge div_unit.clk_i) (valid_i |=> (div_unit.cycles_counter == ((valid_i && op_32bits_i) ? div_unit.CYCLES_32[5:0] : div_unit.CYCLES_64[5:0]))));
