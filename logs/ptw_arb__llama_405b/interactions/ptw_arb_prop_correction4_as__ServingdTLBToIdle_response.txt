The current assertion is failing because it does not consider the case where there is a pending iTLB request waiting to be served. When the dTLB request is completed (ptw_tlb_comm_i.resp.valid == 1'b1), the next state will be SERVING_iTLB if there is a pending iTLB request, not IDLE.

The proposed fix is to add a condition to check if there is a pending iTLB request waiting to be served. If there is, the next state should be SERVING_iTLB, otherwise it should be IDLE.

Here is the corrected assertion:

as__ServingdTLBToIdle: assert property(ptw_arb.current_state == ptw_arb.SERVING_dTLB && ptw_tlb_comm_i.resp.valid == 1'b1 |=> ptw_arb.next_state == ($past(ptw_arb.is_req_waiting_q) && $past(ptw_arb.itlb_req_waiting_q.req.valid) ? ptw_arb.SERVING_iTLB : ptw_arb.IDLE));
